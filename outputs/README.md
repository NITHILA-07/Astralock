# AstraLock Simulation & Benchmark Outputs

This directory stores outputs generated by closed-loop simulation runs and benchmark sweeps.

## Directory Structure

- `runs/`: Contains telemetry time-series (`.csv`) and run summaries (`.json`) for individual runs.
- `benchmarks/`: Contains side-by-side benchmark comparison logs and summaries comparing Baseline (reactive) vs Predictive (AstraLock) coarse tracking across identical seeded scenarios.

## Metrics Recorded

- `acquisition_time_s`: Time (seconds) until continuous lock is achieved for >= 3 consecutive frames.
- `mean_tracking_error_px`: Average distance between ground-truth beacon center and camera optical axis.
- `max_tracking_error_px`: Peak tracking error experienced during the scenario.
- `lock_retention_percent`: Fraction of simulation time the terminal maintained lock.
- `lock_loss_count`: Number of times the beacon left the lock threshold.
- `measured_fps`: Measured frame rate and processing time per frame.
